# v1.0 gate — closed-loop log

Handoff §8 names the v1.0 gate artifact as a "closed-loop recording/log + SWE-bench-lite number." This is the recorded log. The SWE-bench-lite number (A11) is deferred — see *Deferred* below.

## What the gate requires (Handoff §3 GATE)

> failing test → plan, edit real files, run test, read failure, fix, green, commit, stop — within cap, every step undoable, watched end to end.

## The recording

A deterministic "scripted brain" stands in for the model so the harness mechanics can be proven with no API key. Everything else is real: the filesystem, the subprocess, git, and pytest. Reproduce with:

```sh
uv run python examples/demo_closed_loop.py
```

A broken project (`def add(a, b): return a - b`, with a test asserting `add(2, 3) == 5`) is driven to green:

```
workspace: /tmp/tack-demo-XXXXXXXX
task: Make the failing test pass.

  turn 1: bash     ok=False  verify_passed=False     # run pytest → red, failure read back
  turn 2: read     ok=True   verify_passed=False     # inspect calc.py
  turn 3: edit     ok=True   verify_passed=True       # minus → plus; loop sees green, stops

result : success=True  stop_reason=verified  turns=3
verify : pytest -q
HEAD   : 09b6ac264328
summary: (loop saw green on its own verification)
```

## Gate checklist

| Requirement | Met | How |
|---|---|---|
| failing test → read failure | ✓ | turn 1 runs `pytest -q`; non-zero exit + stderr fed back |
| plan, edit **real** files | ✓ | turn 3 `edit` rewrites `calc.py` on disk |
| run test, fix, **green** | ✓ | post-process verification flips to exit 0 → `stop_reason=verified` |
| within iteration cap | ✓ | 3 turns ≪ `max_iterations` |
| every step **undoable** | ✓ | git-per-step commits; `test_closed_loop_is_undoable` resets to baseline and the bug returns |
| watched end to end | ✓ | the `transcript` records each turn's action / tool_ok / verify_passed |
| stop | ✓ | the loop terminates itself on green, not on the model's say-so |

Covered by `tests/test_closed_loop.py` (green in CI) plus the full unit suite for the loop, tools, context, verification, and safety/economics guards (doom-loop, cap, dangerous-command, git).
